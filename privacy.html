SD Coin Privacy Notice

This is a starter notice for the SD Coin demo. The site operator must review it and fill in the real operator identity, contact details, hosting arrangements and retention periods before publishing.

Information the website stores

When you register, the service stores your display name, chosen User ID, email address, salted password hash, internal SD balance and account creation time. It also stores transaction records and mining block metadata needed to operate the demo wallet.

Login and device activity

The browser keeps a short-lived signed login token in session storage. It is cleared when the browser tab/session ends or when you log out. The dashboard sends a heartbeat while you are signed in. The server stores a random browser-generated device session ID, a broad Mobile/Desktop label and a last-seen time to show how many devices are currently active. Old presence records are removed after approximately three minutes.

Mining

Mining is optional and starts only after you press Start Mining on that device. It uses the device's processor and may consume battery and create heat. Mining pauses when the page is hidden. Block records contain the miner's User ID, time, reward, nonce and hashes; these records are visible in the chain viewer.

What this website does not request

The current project does not request GPS location, contacts, camera, microphone, photos, phone number or hardware serial numbers. Do not add such collection without a clear purpose and consent.

Who can access information

The service operator and authorized administrators who control the backend/database may access stored account and transaction data. Hosting and infrastructure providers may process technical request information under their own terms. The operator should document the actual providers and access controls here.

Security and retention

The project uses HTTPS when deployed, salted password hashes, short-lived signed tokens, session revocation on password changes, request rate limits and restricted cross-origin API access. No website can promise perfect security. Account, transaction and chain records remain in the database until the operator deletes them according to a published retention policy. This starter does not yet include self-service account deletion or email-based password recovery.

Your choices

You can stop mining at any time, log out, and choose not to use optional mining. For account access, correction or deletion requests, contact the service operator using the contact details the operator must publish here: [Add your support email/contact].

Demo value notice

SD Coins are internal demonstration credits only. They are not real cryptocurrency, are not redeemable for cash, and should not be treated as money or an investment.
